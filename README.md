# Auralis IPTV Player releases

Signed Android APKs of **Auralis IPTV Player** and the `version.json` manifest read by its in-app updater.
The source code lives in a private repository; this repository only holds release files.

- Latest APK: [com.auralis.iptvplayer-Signed.apk](https://github.com/capogithub/AuralisIptvPlayer-releases/releases/latest/download/com.auralis.iptvplayer-Signed.apk)
- Update manifest: [version.json](https://github.com/capogithub/AuralisIptvPlayer-releases/releases/latest/download/version.json)

Releases are published automatically by the release workflow of the source repository.
Auralis IPTV Player is only a player: it does not provide any channels or content.
